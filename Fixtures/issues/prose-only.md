The board is a remote control, not a mirror of GitHub. Moving a card is the act of
execution: dragging one from Backlog to To Do genuinely spawns a Claude Code run inside a
registered checkout on this machine, and there is no undo for that.

Nothing in this file is a heading and nothing in it is a list. The parser has to keep
every word anyway, because a card's body is arbitrary prose written by whoever filed the
issue, and the panel that renders it has no error state to fall back on.
